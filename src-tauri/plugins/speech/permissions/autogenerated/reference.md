## Default Permission

Lets the WebView run a dictation: ask whether the device can recognise speech at
all, ask for the microphone, start and stop one recognition, and receive its
events. No audio is exposed — the screen receives loudness readings and text,
never a recording.

#### This default permission set includes the following:

- `allow-availability`
- `allow-request-permission`
- `allow-language-support`
- `allow-download-language`
- `allow-open-app-settings`
- `allow-take-dictation-request`
- `allow-start`
- `allow-stop`
- `allow-cancel`
