# Варианты иконки приложения

Пять стилевых вариантов одного знака. Геометрия знака взята без изменений из
Figma-исходника (`xima.keeps-*.svg` в корне) — различается только оформление:
подложка, рамка, заливка знака и тени.

| id | стиль |
| --- | --- |
| `ink` | исходный бренд: графитовый знак на светлой подложке |
| `amber` | тёплая бумага, янтарный знак |
| `midnight` | тёмная подложка, мятный знак со свечением |
| `paper` | контурный знак на кремовом фоне |
| `neon` | индиго-фиолетовый градиент, светлый знак |

## Пересборка

```sh
node assets/app-icons/build-icons.mjs
```

Скрипт перезаписывает `svg/`, `png/` и `variants.json`. Источник правды — сам
скрипт: правки вносим в описание варианта, а не в готовые файлы.

`svg/` — то, что идёт в продукт. `png/` — превью 512×512 (рендер headless-Chrome,
на macOS дополнительно обрезается через `sips`); при отсутствии Chrome шаг
пропускается, SVG всё равно собираются.

## Что дальше

`variants.json` — готовый контракт для будущего переключателя иконки: `id`,
название, описание и акцентный цвет для превью в настройках.

Смена иконки лаунчера на Android делается через `activity-alias` в манифесте
(по алиасу на вариант) и `PackageManager.setComponentEnabledSetting`. Иконки
платформ при этом собираются отдельно из выбранного PNG — `tauri icon` кладёт
результат в `src-tauri/icons` и `src-tauri/gen/android/.../res`.
